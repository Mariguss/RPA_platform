### Проблема. 
В компании есть система без API (старая CRM/ERP, портал поставщика). Данные приходят из других источников: с сайта, из почты, из Excel. Сотрудники переносят их руками: медленно, с ошибками, вечером и в выходные никого нет.

### Решение. 
Робот делает то, что делал бы человек: логинится, заполняет форму, проверяет результат. Заявки принимаются через API и складываются в очередь Kafka. Если робот упал или система недоступна, заявки не теряются и обработаются позже. Ошибки делятся на технические (повторить) и в данных (отдать человеку).

### Где применяется. 
Регистрация клиентов и заказов в легаси-системах, перенос данных между несвязанными системами, работа с порталами госорганов, банков и страховых, массовая загрузка документов.
